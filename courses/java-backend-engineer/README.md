# Java Backend Engineer

A structured roadmap from Java fundamentals to production-quality backend development.

## What You'll Learn

- Java core syntax through advanced language features
- Object-oriented design, data structures, and algorithms
- Backend tooling: Maven, JUnit, Spring Boot, REST APIs
- Databases, JDBC, and concurrency
- Professional practices: design patterns, clean code, architecture, and performance

## Course Structure

| Module | Focus |
|--------|-------|
| [01 – Java Core](modules/01-java-core/) | Syntax, collections, I/O, exceptions, debugging |
| [02 – OOP & Advanced Java](modules/02-object-oriented-programming/) | OOP, DSA, streams & lambdas |
| [03 – Concurrency & Data Access](modules/03-concurrency-and-data-access/) | Threads, JDBC, SQL |
| [04 – Backend Development](modules/04-backend-development/) | Maven, testing, Spring Boot, REST |
| [05 – Software Craftsmanship](modules/05-software-craftsmanship/) | Architecture, patterns, clean code, production |

## Getting Started

1. Follow the [roadmap](ROADMAP.md) in order
2. Complete exercises in each topic's `exercises/` folder
3. Track progress in [PROGRESS.md](PROGRESS.md)
4. Review [interview notes](INTERVIEW-NOTES.md) as you advance

## How Topics Are Organized

```
topic-name/
├── README.md      # Overview and key concepts
├── notes.md       # Your personal notes
├── exercises/     # .java coding exercises
└── examples/      # Reference implementations
```

Java Core uses nested **lesson** folders for foundational drills:

```
java-core/
├── 01-how-java-works/
├── 02-variables-and-primitive-types/
└── ...
```
