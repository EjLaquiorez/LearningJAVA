# Software Engineering Mindset

Learn to think like a software engineer **before** writing code.

This course covers analysis, requirements, domain modeling, and system design — the skills that separate coders from engineers.

## What You'll Learn

- How to analyze problems from a business and engineering perspective
- How to gather, document, and validate requirements
- How to model domains, processes, data, and systems
- How to reverse-engineer and design real-world software

## Course Structure

| Module | Focus |
|--------|-------|
| [01 – Engineering Foundations](modules/01-engineering-foundations/) | Mindset and thinking habits |
| [02 – Requirements Engineering](modules/02-requirements-engineering/) | Capturing what to build |
| [03 – Stakeholder Discovery](modules/03-stakeholder-discovery/) | Working with people who matter |
| [04 – Domain Modeling](modules/04-domain-modeling/) | Rules, limits, and edge cases |
| [05 – Process & User Flow](modules/05-process-and-user-flow/) | How users and systems behave |
| [06 – Data & System Thinking](modules/06-data-and-system-thinking/) | Entities, relationships, and system design |
