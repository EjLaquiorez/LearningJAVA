# Course Overview

## What This Course Is

Software Engineering Mindset teaches you to **think before you code**.

Most beginners jump straight into syntax. Professional engineers start by understanding the problem, the business, the users, and the system — then they write code.

## Who This Is For

- Java learners who want to think like a backend engineer
- Developers preparing for real-world project work
- Anyone who wants to move from "writing code" to "building systems"

## What Makes This Different

This is not a programming course. There are no `.java` files here.

Instead, you will practice:

- Analyzing requirements
- Interviewing stakeholders
- Mapping processes and user journeys
- Modeling data and systems
- Reverse-engineering existing software

These skills directly support the [Java Backend Engineer](../java-backend-engineer/) track.

## Expected Outcome

By the end, you should be able to take a vague business idea and break it down into clear requirements, domain rules, data models, and system designs — before writing a single class.
