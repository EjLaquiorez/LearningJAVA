# How to Use This Course

## Step-by-Step Workflow

For each topic in the [roadmap](../ROADMAP.md):

1. **Read** the topic `README.md` — understand what it covers
2. **Research** — use [RESOURCES.md](../RESOURCES.md) for external reading
3. **Write** — fill in your `notes.md` with what you learned
4. **Practice** — complete exercises in the `exercises/` folder
5. **Study** — review examples in the `examples/` folder
6. **Track** — mark the topic complete in [PROGRESS.md](../PROGRESS.md)


## Tips

- Pair this course with hands-on Java projects in [projects/mini/](../../projects/mini/)
- Apply each topic to a system you already know (banking app, social media, etc.)
- Use the [system analysis docs](../../docs/system-analysis/) as reference material

## Suggested Pace

- **1 topic per day** — finish in about 4 weeks
- **2–3 topics per week** — finish in about 2 months

Adjust based on how deeply you practice each topic.
