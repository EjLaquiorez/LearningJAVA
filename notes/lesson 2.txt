# Part 1 — What is a Variable?

Imagine you're working in a warehouse.

Every box has:

* A label
* A space to store something

Example:

```
+-----------+
| Age       |
|    22     |
+-----------+
```

A **variable** is just like that box.

It has:

* A **name**
* A **value**
* A **data type**

In Java:

```java
int age = 22;
```

Let's break it down.

```
int
```

The **type**.

```
age
```

The **variable name**.

```
22
```

The value stored.

---

# How Memory Works

When Java runs:

```java
int age = 22;
```

The JVM stores something similar to this:

```
Memory

Address      Value

1001  ------> 22
```

The variable name (`age`) points to that memory location.

Think of it like this:

```
age

↓

22
```

You don't need to know the actual address.

The JVM manages memory for you.

General syntax:

Example:

# Part 3 — Primitive Data Types

Java has **8 primitive data types**.

Don't memorize them immediately.

Understand what each is for.

---

## 1. int

Stores whole numbers.

```java
int age = 22;

int population = 1000000;
```

---

## 2. double

Stores decimal numbers.

```java
double price = 19.99;

double pi = 3.14159;
```

---

## 3. boolean

Only two values:

```java
true

false
```

Example:

```java
boolean isStudent = true;

boolean loggedIn = false;
```

---

## 4. char

Stores ONE character.

Notice:

Single quotes.

```java
char grade = 'A';

char letter = 'Z';
```

Wrong:

```java
char grade = "A";
```

Because double quotes create a `String`.

---

## 5. byte

Small integers.

Rarely used.

```java
byte number = 100;
```

---

## 6. short

Medium integers.

```java
short year = 2026;
```

---

## 7. long

Very large integers.

Must end with `L`.

```java
long distance = 10000000000L;
```

---

## 8. float

Decimal numbers.

Must end with `F`.

```java
float temperature = 36.5F;
```

---

# Primitive Summary

| Type    | Example    |
| ------- | ---------- |
| byte    | 100        |
| short   | 1000       |
| int     | 22         |
| long    | 100000000L |
| float   | 12.5F      |
| double  | 12.5       |
| char    | 'A'        |
| boolean | true       |

# Part 4 — String (Reference Type)

A `String` is **not** a primitive.

It is an object.

Example:

```java
String name = "John";
```

Notice:

```
String
```

has a capital **S**.

This is one of the most common beginner mistakes.

Correct:

```java
String city = "Puerto Princesa";
```

Wrong:

```java
string city = "Puerto Princesa";
```

Java is **case-sensitive**.

---

# Part 5 — Printing Variables

Instead of printing fixed text:

```java
System.out.println("John");
```

Print the variable:

```java
String name = "John";

System.out.println(name);
```

Output:

```
John
```

---

Multiple variables:

```java
String name = "John";

int age = 22;

System.out.println(name);

System.out.println(age);
```

Output:

```
John
22
```

---

# Part 6 — String Concatenation

Java joins text using `+`.

Example:

```java
String name = "John";

System.out.println("Hello " + name);
```

Output:

```
Hello John
```

---

More example:

```java
int age = 22;

System.out.println("Age: " + age);
```

Output:

```
Age: 22
```

# Part 7 — Variable Naming Rules

Good:

```java
firstName

lastName

studentAge

bankBalance
```

Bad:

```java
a

x

asdf

test123
```

---

Java convention:

Use **camelCase**.

Example:

```
studentName

phoneNumber

monthlySalary

birthYear
```

---

# Part 8 — Changing Variable Values

Variables can change.

```java
int score = 50;

score = 100;

System.out.println(score);
```

Output:

```
100
```

Notice:

The second line has **no `int`**.

Because the variable already exists.

Wrong:

```java
int score = 50;

int score = 100;
```

This causes a compile-time error because you're declaring the same variable twice in the same scope.

---

# Part 9 — Type Conversion (Casting)

Sometimes Java converts values.

Example:

```java
int age = 22;

double result = age;
```

This works automatically.

Called:

**Implicit Casting**

```
int

↓

double
```

No data is lost.

---

The opposite:

```java
double price = 19.99;

int whole = (int) price;
```

Output:

```
19
```

The decimal part is removed.

This is:

**Explicit Casting**

---

# Part 10 — Memory Visualization

Example:

```java
String name = "John";

int age = 22;

boolean employed = true;
```

Imagine memory like this:

```
Memory

name -------> "John"

age --------> 22

employed ---> true
```

Variables point to values stored in memory.

The JVM manages the details for you.

# Common Beginner Mistakes

### 1.

Wrong:

```java
int age = "22";
```

Correct:

```java
int age = 22;
```

---

### 2.

Wrong:

```java
char letter = "A";
```

Correct:

```java
char letter = 'A';
```

---

### 3.

Wrong:

```java
string name = "John";
```

Correct:

```java
String name = "John";
```

---

### 4.

Wrong:

```java
int age;

System.out.println(age);
```

Local variables must be initialized before use.

Correct:

```java
int age = 22;

System.out.println(age);
```
